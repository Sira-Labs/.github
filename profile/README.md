**Software you own, built in the open.** Self-hostable, spec-driven, built with AI agents from
written specs and decision records. Each project is named for a moment of the _Sīra_, the life
of the Prophet ﷺ, and the name says what it is for.

| Project                                                   | What it is                                                                                           | Named for                                                                    |
| --------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **[Thawr](https://github.com/thedatadudech/Thawr)**       | Self-hosted WireGuard mesh VPN / ZTNA. One binary, no cloud, works offline.                          | The cave of the Hijra: hidden, protected, reachable only by those who belong |
| **[Tabayyun](https://github.com/thedatadudech/Tabayyun)** | Verifies industrial time series before anyone acts on them: checks, a score per series, explanations | _Tabayyun_: verify a report before acting on it                              |
| **[Suffa](https://github.com/thedatadudech/Suffa)**       | Offline-first Arabic learning with your teacher, your class and an AI tutor                          | The platform of learning in the Prophet's ﷺ mosque                           |
| **Arqam** (in development)                                | One connected journey to AI engineer, data scientist or AI researcher, from openly licensed material | _Dār al-Arqam_, the house where the first Muslims learned                    |

**How we build:** vision, ADRs, threat model and acceptance tests first; code second. Everything
self-hostable (CapRover, Postgres, S3-compatible storage), no secrets in code, semantic commits.
